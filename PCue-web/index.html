PCue

현장용 음원·영상 재생기

관제 창은 주 모니터에 두고, 영상만 선택한 디스플레이로 보냅니다.

PCue-Setup.exe 받기 릴리스

Windows 10/11 x64 · self-contained

재생 목록

파일 추가·드래그 앤 드롭, 번호·길이 표시, 위아래 정렬, Delete로 제거. 자동 다음 재생으로 큐를 이어갑니다.

디스플레이 분리

출력 모니터를 고른 뒤 영상 출력을 켜면 그 화면만 전체화면으로 나갑니다. 관제 창에는 영상이 뜨지 않습니다.

조작

재생·일시정지·시크·볼륨. ←/→ 시크, Shift+←/→ 이전·다음, Esc로 출력 끄기.

설치

PCue-Setup.exe를 실행하면 됩니다. 바탕화면 바로가기와 설치 후 실행 여부를 고를 수 있습니다. LibVLC가 포함되어 별도 런타임 설치는 필요 없습니다.
