# PCue (피큐)

현장용 음원·영상 재생기입니다. 관제 창은 주 모니터에 두고, 영상만 선택한 디스플레이로 보냅니다.

Windows 10/11 x64 · WPF · LibVLCSharp · Velopack

## 기능

- 재생 목록: 파일 추가, 드래그 앤 드롭, 번호·길이, 위아래 정렬, Delete로 제거
- 자동 다음 재생 ON/OFF
- 관제 UI / 영상 출력(선택 디스플레이) 분리
- 재생·일시정지·정지·이전·다음·시크·볼륨·음소거
- 페이드 정지: 정해 둔 시간(1~10초) 동안 소리를 줄이며 정지, 한 번 더 누르면 즉시 정지
- 큐 설정 패널(선택한 큐)
  - 재생 구간: 시작·종료 지점 입력 또는 재생 중 "현재 위치"로 지정, 시크 바에 표시
  - 페이드 인/아웃(소리)
  - 끝나면: 기본(자동 다음 따름) / 다음 큐 / 정지 / 마지막 장면에서 멈춤(영상) / 반복
  - 예약 재생: N분 후 또는 특정 시각, 목록에 남은 시간 표시, 예약 중에는 절전 방지
- 설치본에서 GitHub Releases 기반 업데이트 안내

## 단축키

| 키 | 동작 |
| --- | --- |
| `Space` | 일시정지 / 계속 |
| `Enter` | 선택 항목 재생 |
| `F` | 페이드 정지 (한 번 더 누르면 즉시 정지) |
| `I` / `O` | 재생 중인 큐의 시작 / 종료 지점을 현재 위치로 |
| `↑` / `↓` | 목록 선택 이동 |
| `←` / `→` | 시크 |
| `Shift` + `←` / `→` | 이전 / 다음 |
| `Delete` | 선택 항목 제거 |
| `Esc` | 영상 출력 끄기 |

## 개발 실행

```bash
cd PCue
dotnet run
```

## 폴더 배포

```bash
cd PCue
dotnet publish -p:PublishProfile=FolderProfile
```

출력: `bin/Release/net10.0-windows/win-x64/publish/`

폴더 전체를 복사해 `PCue.exe`를 실행합니다. LibVLC가 포함되어 있습니다.  
`dotnet run` / 미설치 빌드에서는 업데이트 UI가 뜨지 않습니다.

## 사용

1. 파일을 추가하거나 재생 목록에 끌어다 놓습니다.
2. 출력 디스플레이를 고른 뒤 **영상 출력**을 켭니다.
3. 영상은 선택한 디스플레이에만 전체화면으로 나갑니다. 관제 창에는 영상이 뜨지 않습니다.
4. **자동 다음**이 켜져 있으면 한 항목이 끝나면 다음을 재생합니다. 큐 설정의 **끝나면**을 바꾼 큐는 그 설정을 따릅니다.
5. 관제 창에서 `Esc`로 영상 출력을 끌 수 있습니다. 음원 큐·정지 시 출력 화면은 검정으로 유지됩니다.
6. 재생 중인 큐의 시작 지점·반복 설정을 바꾸면 다음 재생부터 적용됩니다. 종료 지점(현재 위치보다 뒤일 때)·페이드 아웃·끝나면(반복 제외)은 바로 적용됩니다.
7. 예약 시각에 다른 큐가 재생 중이면 끊고 예약한 큐를 재생합니다. PC가 잠들어 10초 넘게 지난 예약은 실행하지 않습니다.
8. 큐 설정과 예약은 재생 목록과 함께 메모리에만 있으며, 프로그램을 닫으면 사라집니다.

## 요구 사항

- Windows 10/11 x64
- 배포본은 self-contained라 .NET 런타임 별도 설치가 필요 없습니다.
